# codealpha_Eecommers-store
A Simple E-commerce Store developed using Python Django, HTML, CSS, JavaScript, and SQLite. This project allows users to browse products, view product details, add items to a shopping cart, register, log in, and place orders. Developed as part of the CodeAlpha Full Stack Development Internship.
# 🛒 CodeAlpha Task 1 – Simple E-commerce Store

## 📌 Project Description
The Simple E-commerce Store is a web-based shopping application developed as part of the CodeAlpha Full Stack Development Internship.

This application allows users to browse products, view product details, add products to their shopping cart, register, log in, and place orders.

## 🚀 Technologies Used
- Python
- Django
- HTML
- CSS
- JavaScript
- SQLite

## ✨ Features
- User Registration
- User Login and Logout
- Product Listings
- Product Details Page
- Add to Shopping Cart
- Remove Products from Cart
- Order Processing
- Database Integration

## ⚙️ Installation and Setup

### Step 1: Clone Repository
```bash
git clone YOUR_GITHUB_REPOSITORY_LINK
```

### Step 2: Open Project Folder
```bash
cd CodeAlpha_SimpleEcommerceStore
```

### Step 3: Install Django
```bash
python -m pip install django
```

### Step 4: Apply Database Migrations
```bash
python manage.py migrate
```

### Step 5: Run the Project
```bash
python manage.py runserver
```

### Step 6: Open in Browser
```text
http://127.0.0.1:8000/
```
